# 校园网助手 · 使用说明

一个可视化控制台，用来管理**路由器上的校园网自动登录**。
不用记命令、不用登路由器后台，开一个窗口就能看状态、开开关、改时段、看日志。

---

## 一、怎么启动

**推荐：双击** `启动校园网助手.bat`

**或者** 命令行：

```bash
python campus_console.py
```

命令行还带三个自检开关，出问题时很好用：

```bash
python campus_console.py --selftest   # 检查环境、解析、加密等 60 项，不联网
python campus_console.py --smoke      # 只把界面构建一遍再退出，不联网
python campus_console.py --shot       # 把每种界面状态各截一张图，用来走查外观
```

> 首次启动如果提示缺 `paramiko`，主界面顶部会出现一条琥珀色提示条，
> 点上面的「一键安装」即可（约 10–30 秒）；
> 也可以手动执行 `python -m pip install paramiko`。

## 一·补 打包成 exe（对方不用装 Python）

**推荐：双击** `发布\校园网助手-通用版.exe` —— 单文件、自带运行环境，双击就能用。

> 本仓库是公开版本，**只发布通用版**（三个凭据字段全部清空）。
> 自用版带你自己的预置连接信息，不随仓库分发 —— 想自用就把值填回
> `campus_console.py` 的 `PRESET` 再重新打包一次。

要重新打包（改了源码之后）：

```bash
"C:\Users\<你>\AppData\Local\Programs\Python\Python313\python.exe" 打包exe.py
```

> 必须用**系统 Python**。管理版 Python 没有 tkinter，用它打出来的 exe 起不来。

跑完会往 `发布\` 里放两个 exe，**它们不是重复的，别拿错**：

| 文件 | 给谁 | 里面的凭据 |
|---|---|---|
| `校园网助手.exe` | **自己用** | 带你自己的预置连接信息，双击即用 |
| `校园网助手-通用版.exe` | **发给别人** | 学号、校园网密码、路由器 SSH 密码全部清空 |

**为什么要分两个**：源码顶部 `PRESET` 写死了你的学号密码，直接打包发出去
等于把账号一起发出去。打包脚本在产通用版之前会用正则把三个敏感字段清空，
**清不干净就直接报错、不出包**（宁可失败也不产脏包）。`host` / `port` / `user`
不清 —— 它们是「小米出厂默认网关 + dropbear 只有 root」这类通用事实，留着反而方便别人。

**「通用版真没带凭据」是怎么验证的**（这一步很关键）：

- ❌ 不能用 `strings 校园网助手-通用版.exe | findstr <你的学号>` 这种办法。
  exe 里的字节是**压缩**存储的，扫不到**不代表**没有；实测连**自用版**都扫不到，
  说明这个方法根本没有判定力。
- ✅ 正确做法是让 exe 自己把配置解出来。程序内置了无界面开关：

  ```bash
  校园网助手-通用版.exe --dump-config
  ```

  它走的是正常启动时的 `load_config()` → `apply_preset()` 流程，只报长度不报明文。
  打包脚本会自动跑一遍并核对：通用版必须 `campus_user=空`、`路由器密码=无`，
  自用版必须已填充。结果落在 `发布\<名字>.自检.txt`。

打包脚本还会顺带做：两个 exe 各跑一次 `--selftest`（60 项）和 `--smoke`（界面构建）。
全部通过才返回 0。完整过程见 `发布\打包日志.txt`。

**几个使用上的注意**：

- exe 是**单文件**且**已内置 payload**，对方不需要另找部署包。
- exe **没有代码签名**，第一次运行 Windows SmartScreen 可能弹「未知发布者」，
  点「更多信息 → 仍要运行」即可。
- 程序自己的配置仍写在 `%USERPROFILE%\.campusnet_console.json`；
  另外会在 `%LOCALAPPDATA%\CampusNetAssistant\` 放一个 `campus.ico`
  和（无控制台时的）`console_output.txt`，属正常。
- 发给同学时把 `发布\使用说明（发给同学）.txt` 一起发过去 ——
  对方那台机器得先开 SSH 才能用。

## 二、首次使用（三步）

打开窗口 → 右下角 **设置**。**里面已经把这台路由器的连接信息预填好了**，
检查一眼就能直接部署：

| 步骤 | 哪一块 | 状态 |
|---|---|---|
| 1 | 路由器连接 | 已预填：地址 `192.168.31.1`（小米路由器默认网关）、端口 22、用户 `root`、路由器 SSH 密码 |
| 2 | 部署 / 更新到路由器 | 已预填：校园网账号 `<你的学号>` 和密码 |
| 3 | 部署 / 更新到路由器 | 确认「程序文件」目录，点 **部署 / 更新** |

点「部署 / 更新」后程序会自动做完这一串事：

1. 连接路由器（第一次会问你是否信任这台机器，选是）
2. 上传程序文件到 `/data/campus/v2`
3. 把账号密码加密写进路由器（密钥单独存放）
4. 校验凭据、写定时任务、设置总开关
5. 实测一次登录，确认真的能上网

看到「部署完成」就可以关掉设置窗口了。

### 预填的值是哪来的 / 怎么改

这套连接信息写死在 `campus_console.py` 顶部的 `PRESET` 常量里，来源是：

- **SSH 侧** —— 路由器地址取本机 WLAN 的默认网关（`192.168.31.1`，也是小米出厂默认）。
  小米 / 红米路由器开启 SSH 后，dropbear 里只有 `root` 一个账号
  （xmir-patcher 开锁工具全流程也用 root）；`Xiaomi_xxxx` 那种格式是路由器
  **后台网管页**的登录账号，不是 SSH 账号，填了会认证失败。
- **校园网侧** —— `Downloads\CampusNet-AutoLogin-main\...\school_network.py`
  里的 `USERNAME` / `PASSWORD` 两个常量。

怎么改、怎么撤销：

- **改**：直接在设置面板里改，点「保存」就以你的配置为准，预置不会再来覆盖
  （靠 `PRESET_VERSION` 版本号做一次性迁移，只在版本号变大时才灌一次）。
- **撤销预置**：把 `PRESET` 里对应项改成 `''`，并把 `PRESET_VERSION` 加 1。
  ⚠️ 不改版本号的话，老值还留在配置文件里，改了等于没改。
- **密码明文问题**：`PRESET` 里是明文密码（这个程序只在本机自己用）。
  点一次「保存」后，密码就会以 Windows DPAPI 密文写进配置文件；
  「清空已保存的密码」清掉之后也不会被预置重新灌回来。
- ⚠️ 别把带密码的 `campus_console.py`、`%USERPROFILE%\.campusnet_console.json`
  或整个程序文件夹发给别人。

## 二·补 路由器 SSH 已经开好了（2026-09-17）

这台小米路由器原本**没开 SSH**（小米出厂就是不开的），已经用 `xmir-patcher-main`
打通了，**不用再重复操作**。设备与账号信息：

| 项 | 值 |
|---|---|
| 型号 | Xiaomi Router AC1200（R4AV2），固件 2.30.28 |
| 地址 / 端口 | `192.168.31.1` / `22` |
| 用户 / 密码 | `root` / `<你的密码>` |
| Web 后台密码 | `<你的密码>`（同一个） |

**为什么重启也不会丢**（当时做了三重持久化）：

1. `nvram set ssh_en=1` + `nvram commit`
2. crontab 每分钟跑一次 `/etc/crontabs/patches/ssh_patch.sh`（掉了会自动重新拉起来）
3. 防火墙 include `firewall.auto_ssh_patch` 指向同一个脚本（开机时执行）

顺带开启了 `boot_wait=on`、`uart_en=1`（万一刷坏了更容易救回来）。

**几件要记住的事**：

- **别在路由器后台升级固件**。升级会清掉上面的补丁和 XMiR-SSH，SSH 就没了
  （重新用 xmir-patcher 开一次即可，几分钟的事）。
- **Telnet(23) 已经关掉了**（2026-09-18）。开 SSH 时它作为后备通道被一起打开，
  明文协议，局域网里谁都能连，所以收尾时关掉了。想确认或重新开关：
  ```sh
  netstat -ln | grep ':23 '            # 没有输出就是已关
  # 关：
  /etc/init.d/telnet disable ; /etc/init.d/telnet stop ; nvram set telnet_en=0 ; nvram commit
  # 再开（万一 SSH 连不上了，用它救急）：
  /etc/init.d/telnet enable  ; /etc/init.d/telnet start ; nvram set telnet_en=1 ; nvram commit
  ```
  关掉是安全的：SSH 有 cron（每分钟）+ 防火墙 include 双重自愈，而且后台 Web 页也能进。
- **想撤销**：在 `xmir-patcher-main\xmir-patcher-main` 目录跑
  `python install_ssh.py uninstall`（配合 `nvram set ssh_en=0`）。
- 开 SSH 时 root 密码会被工具设成 `root`，之后已手工改成 `<你的密码>`（与上面表格一致）。
- **这台路由器没有 SFTP，也没有 scp**：XMiR-SSH（dropbearmulti）没编译 sftp 子系统。
  程序部署时会**自动改用 base64 通道**传文件（走 SSH 执行通道的 stdin），
  日志里会出现一句「已自动改用 base64 通道上传」—— 这是正常的，不用管。

**这台路由器还有一个已知特性**：原厂固件**不带 `openssl`**，而 `/data` 与 `/etc`
共用一个 1MB 分区（实测只剩 ~130KB），装不下。结果是路由器上**没法做 AES 加密**，
校园网账密只能**降级成 base64 存放**（等同明文，仅靠文件权限保护）。
部署时会出现一条提醒，属正常。详见一键部署包 `使用说明.md` 的 Q7。

## 三、主界面看什么

顶部是**总开关状态卡片**，一眼看出路由器现在会不会自动登录。
下面四块小状态：

- **自动重连** —— 定时任务是否就绪。若显示「旧版本」，说明路由器上还是旧任务
  （不含开关判定），总开关不会生效，需要重新部署一次
- **登录程序** —— 路由器上的脚本文件是否就绪
- **定时服务** —— crond 是否在运行。它停了，自动登录就不会被触发
- **连接方式** —— 当前用的 SSH 后端（paramiko / plink）

再往下是**实时日志**，每 15 秒自动拉一次路由器日志，可以暂停、清屏、导出。
底部状态栏显示路由器地址、最近开启时间和配置文件位置。

> 界面会跟随 Windows 缩放自动调整（125% / 150% / 200% 都清晰），
> 窗口尺寸始终保持在屏幕可用区内，不会被任务栏挡住底部按钮；
> 图标是程序自己画的矢量图，不依赖任何图片文件。

## 四、为什么要「总开关」

学校如果**限制同一账号只能一台设备在线**，路由器一直自动登录会把你在教室、
图书馆的手机/笔记本踢下线。

所以程序默认给了你一个**总开关**：

- **关闭** → 定时任务直接跳过，路由器不登录，你随便在哪台设备上都正常用
- **开启** → 路由器接管，断线自动重连

主界面点一下就能切换，一秒钟的事，不用重新部署。

> 小提示：定时任务里的探测请求（判断是否在线）是只读的，**不会**把你踢下线；
> 只有真正发认证请求才会建立会话。所以就算一直开着，也只是"发现掉线就重连"。

## 五、自动时段（可选）

不想手动开关，就打开「自动时段」：

- 例如 **每天 08:00 关闭、22:00 开启** → 白天你在外面用手机，晚上回宿舍路由器自动接管

这两个时间会写进路由器的定时任务里，和主定时任务互不干扰（带独立标记，
改时段时只替换自己那两行，不会弄乱别的）。

## 六、其它功能

- **托盘图标** —— 关窗口不退出，缩到右下角托盘；右键可显示/退出
- **开机自启** —— 设置里勾选，开机后直接静默进托盘
- **导入/导出配置** —— 设置页可导出 JSON 配置，换电脑不用重填
- **清除已存密码** —— 设置里一键清空本机保存的密码
- **本机日志** —— `%USERPROFILE%\.campusnet_console.log`
- **程序配置** —— `%USERPROFILE%\.campusnet_console.json`（密码用 Windows DPAPI 加密，换机器读不出来）

## 七、常见问题

**连不上路由器**
这台路由器的 SSH 已经开好了（见「二·补」），所以先查这三点：
① 电脑是不是连着这台路由器的 WiFi（不是手机热点、不是邻居家的）；
② 地址有没有改过（默认就是 `192.168.31.1`，也就是你电脑的默认网关）；
③ 路由器刚重启过的话，给它一分钟 —— cron 会自动把 SSH 拉起来。
还不行就在设置里点「测试连接」，会给出具体错误。程序也支持 PuTTY 的
plink 作为备选后端，装了 PuTTY 会自动识别。

**部署成功但上不了网**
点主界面的「立即登录一次」手动跑一次，看日志里报什么。
常见原因是校园网账号密码填错了，或者学校要求先在浏览器里改过密码。

**界面字太大/太小**
程序会跟随 Windows 缩放自动调整，不需要手动设置。

**想彻底卸载**
路由器上执行 `crontab -e` 删掉带 `campus_login.sh` 的那行，
再删掉 `/data/campus` 目录即可；本机删掉 `%USERPROFILE%\.campusnet_console.*` 两个文件。

## 八、环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| Python | 3.10 以上（含 tkinter，官方安装包默认自带）—— **只跑 exe 的话不需要装 Python** |
| 必装 | `paramiko`（SSH 连接） |
| 可选 | `pystray` + `Pillow`（托盘图标） |

没装可选依赖也能正常用，只是没有托盘图标。

> `发布\` 下的两个 exe 已把 Python、tkinter、paramiko、Pillow、pystray **全部内置**，
> 目标机器什么都不用装，双击即用（每个约 24 MB）。
