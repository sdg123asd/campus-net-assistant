# 校园网助手

宿舍路由器**自动登录校园网（Portal 认证）**的完整方案，含 Windows 图形控制台和路由器侧部署包。

学校如果限制「同一账号只能一台设备在线」，路由器一直自动登录会把你在教室、图书馆的手机/笔记本踢下线。
本项目给了一个**总开关**：关闭时路由器完全不碰网络，开启时才接管、断线自动重连。

> ⚠️ **本仓库不含任何账号密码。** 源码里的凭据字段一律留空，首次使用时自己填写。

---

## 组成

| 目录 | 说明 |
|---|---|
| `校园网助手/` | Windows 端 Tkinter 控制台（单文件 `campus_console.py`）。图形化看状态、开总开关、设自动时段、看实时日志，也能一键把程序部署到路由器 |
| `校园网自动登录-一键部署/` | 路由器侧部署包（PowerShell + POSIX sh）。不依赖控制台也能单独部署、单独开关 |

两个组件可以分开用：只想部署的话，`一键部署` 目录里双击 `一键部署.bat` 就行。

---

## 特性

- **图形界面**：不用记命令、不用登路由器后台，一个窗口管全部
- **总开关**：一秒钟切换路由器是否接管登录，改完立即生效、不用重新部署
- **自动时段**：例如每天 08:00 关、22:00 开，写进路由器定时任务，与主任务互不干扰
- **断线自动重连**：定时探测（只读，不会把你踢下线），发现掉线才发起认证；失败带冷静期
- **连接后端双备份**：优先 `paramiko`，装了 PuTTY 也能自动识别 `plink`
- **传输通道自适应**：路由器没有 SFTP/scp 时自动降级走 base64 通道
- **高 DPI 适配**：125% / 150% / 200% 缩放下界面不糊、按钮不被任务栏挡住
- **可打包成单文件 exe**：自带 Python + tkinter + paramiko + Pillow + pystray，目标机器什么都不用装

```
校园网自动登录-一键部署/
├── campus-auth-easy-deploy/
│   ├── deploy.ps1           # 主部署脚本（上传程序、写凭据、装定时任务、实测登录）

```

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| Python | 3.10 以上，需带 tkinter（官方安装包默认自带） |
| 必装 | `paramiko`（SSH 连接） |
| 可选 | `pystray` + `Pillow`（托盘图标）；PuTTY 的 `plink`（备用后端） |

只跑 `发布\` 里的 exe 的话，**不需要装 Python 和任何依赖**。

## 快速开始

### 1. 路由器先开 SSH

小米 / 红米路由器出厂不带 SSH，需要先解锁。**本仓库不含第三方开锁工具**，
请自行搜索 `xmir-patcher` 之类的项目（解锁后 SSH 账号只有 `root`，
`Xiaomi_xxxx` 那种是**后台网管页**账号，不是 SSH 账号）。

> ⚠️ 解锁 SSH 后**别在路由器后台点升级固件**，会清掉补丁。

### 2. 两种部署方式，选一个

**方式 A：图形控制台（推荐）**

```bash
cd 校园网助手
python campus_console.py
```

打开窗口 → 右下角「设置」→ 填路由器连接信息和校园网账号密码 → 点「部署 / 更新」。
程序会自动上传文件到 `/data/campus/v2`、写凭据、装定时任务、设置总开关，并实测一次登录。

**方式 B：直接用部署包**

```bash
cd 校园网自动登录-一键部署/campus-auth-easy-deploy
```
双击 `一键部署.bat`，按提示输入路由器密码和校园网账号密码即可。
以后开关自动登录双击 `校园网开关.bat`。

### 3. 首次运行要填的凭据

源码顶部的 `PRESET` 三个字段（`router_password` / `campus_user` / `campus_password`）
**在本仓库里是空的**。在设置面板里填一次并点「保存」，密码会以 Windows DPAPI 密文
写进 `%USERPROFILE%\.campusnet_console.json`，明文不会落盘。

> 想让它「打开就预填好」：把你的值填回 `PRESET`，并把 `PRESET_VERSION` 加 1
> （版本号不变的话旧配置还在，新值不会生效）。

## 打包成 exe

```bash
python 打包exe.py
```

跑完在 `发布\` 下生成两个 exe（各约 24 MB）：

| 文件 | 给谁 | 凭据 |
|---|---|---|
| `校园网助手.exe` | 自己用 | 带你自己的预置连接信息 |
| `校园网助手-通用版.exe` | 发给别人 | 学号、校园网密码、路由器密码**全部清空** |

打包脚本在产通用版之前会用正则清空三个敏感字段，**清不干净就直接报错、不出包**。
它还会自动跑 `--selftest`（60 项）和 `--smoke`（界面构建）验证，全通过才返回 0。
「通用版真没带凭据」怎么验证见 `使用说明.md`。

## 已知限制

这些是实测过的固有限制，不是 bug：

- **路由器没有 openssl**，且 `/data` 只剩 ~130 KB 装不下 → 路由器上做不了 AES。
  校园网账密只能降级成 **base64** 存放（等同明文，仅靠文件权限保护）。
- **路由器没有 SFTP / scp**（XMiR-SSH 没编译 sftp 子系统）→ 部署时自动改走
  base64 通道（操作 SSH 执行通道的 stdin），日志里会提示一句，属正常。
- 不同路由器固件差异较大，本项目在 **Xiaomi Router AC1200（R4AV2，固件 2.30.28）** 上实测通过。
