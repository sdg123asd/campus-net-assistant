# 校园网自动登录 · 使用说明

> 这份说明写给任何会用电脑的人看，不需要懂技术。
> 看完照着做，大概 3 分钟搞定。

---

## 一、这个东西是干什么的？

一句话：**让路由器自己帮你登录校园网，你不用再手动登录了。**

打个比方：

- 校园网就像学校的大门，进去要报一遍学号和密码
- 以前每次上网，你都得自己"报一次"
- 这个小程序 = 给路由器请了个**看门小助手**，它每 2 分钟往门口看一眼：
  - 发现门关着（没登录）→ 自动拿你的账号密码去报一次
  - 发现门开着（能上网）→ 什么都不做，安静待着

装好之后，你的手机、电脑连上 Wi-Fi 就能直接上网，不用再打开登录页面。

另外还配了一个**总开关**（在 `校园网开关.bat` 里）：学校若限制"一个账号同时只能一台设备在线"，
你离开宿舍去教室时把它关掉就行，免得它和你的手机抢同一个账号。详见第五节。

---

## 二、开始之前，先准备这 4 样

| 要准备的东西 | 说明 |
|---|---|
| 1. 一台 Windows 电脑 | Win10 或 Win11 都行 |
| 2. 连上路由器的网络 | 电脑要连这个路由器的 Wi-Fi，或者插网线 |
| 3. PuTTY 小工具 | 免费的，见下面第三步（如果电脑上已经有了就跳过） |
| 4. 两个密码 | ① 你的校园网账号密码 ② 路由器的登录密码 |

---

## 三、三步搞定

### 第 1 步：解压

把压缩包解压成一个文件夹（放桌面就行）。

⚠️ **注意：一定要"解压到文件夹"，不要打开压缩包直接单独把里面的文件拖出来**，否则程序找不到需要的文件。

解压完，文件夹里应该是这样：

```
campus-auth-easy-deploy\
├── 一键部署.bat        ← 第一次装的时候双击这个
├── 校园网开关.bat      ← ★ 以后开/关自动登录，双击这个
├── deploy.ps1          ← 部署程序本体（别动它）
├── switch.ps1          ← 开关程序（别动它）
├── 使用说明.md         ← 就是这份说明
└── payload\            ← 要装进路由器的东西（别动它）
```

### 第 2 步：确认电脑上有 PuTTY

这个程序需要用到 PuTTY 里的两个小工具（plink 和 pscp）来把文件传到路由器。

- **怎么知道有没有？** 直接做第 3 步，程序会自己找。找不到它会弹出一段提示告诉你去哪下载。
- **想先装好？** 打开 <https://www.putty.org>，下载 64-bit 安装包，双击，一路点 Next 装完即可（免费）。

### 第 3 步：双击「一键部署.bat」

会弹出一个黑色窗口，里面是中文提示。**照着提示输入就行**：

| 屏幕上的提示 | 你要输入 | 举个例子 |
|---|---|---|
| 路由器地址 [192.168.31.1] | 直接按回车（用默认的） | 192.168.31.1 |
| 路由器登录用户 [root] | 直接按回车 | root |
| 路由器登录密码 | 你**路由器**的密码 | （你自己知道） |
| 校园网账号（学号） | 你平时登录校园网用的账号 | 2023123456 |
| 校园网密码 | 你的校园网密码 | （你自己知道） |
| 现在启用自动登录吗？(Y/n) | 人在宿舍按回车；马上去教室输 n | Y |

> 💡 **输入密码时屏幕上什么都不显示，这是故意的**（防止被旁边的人看到）。正常打字，打完按回车即可。

输完会显示一遍"请确认"，按 `Y` 再回车，它就开始自动干活了。

**接下来大约 20 秒，你什么都不用做**，看着它跑完就行：

```
[1/6] 连接路由器
[2/6] 上传程序文件到路由器
[3/6] 设置文件权限
[4/6] 加密保存校园网账号密码
[5/6] 设置定时任务 + 安装总开关
[6/6] 测试一下
```

看到 **「部署完成」** 四个大字，就成功了。按任意键关掉窗口。

---

## 四、装好之后会怎样？

- 路由器**每 2 分钟**自动检查一次网络，时间范围是**每天早上 7 点到晚上 11 点**
- 一旦发现需要登录，就用你的账号密码自动登录
- **但只有在"总开关"开着的时候才会登录**（见下面第五节，很重要）

---

## 五、★ 单会话学校必读：总开关

### 先判断你是不是这种情况

> 你在教室/图书馆连校园网，**刚登上就断**；回宿舍连 WiFi 又是好的。

如果符合，说明学校限制「**一个账号同时只能一台设备在线**」。这种情况下：

- 路由器一登录，你的账号就"占用"在路由器上
- 你在教室用同一账号登录 → 会把路由器顶下线
- 而路由器每 2 分钟就检查一次，发现掉线 → 立刻再登回去 → **你又被顶下线**

结果就是你在外面根本用不了（路由器永远抢得比你快）。**所以必须能把它关掉。**

### 什么时候开、什么时候关

| 场景 | 该怎么做 |
|---|---|
| 回到宿舍，想让 WiFi 能上网 | 双击「校园网开关.bat」→ 选 **1 开启** |
| 离开宿舍去教室/图书馆 | 双击「校园网开关.bat」→ 选 **2 关闭** |
| 忘了现在是开还是关 | 双击 → 选 **3 查看状态** |

关闭之后，路由器**完全不会**再自动登录，你在外面用校园网不会被打扰。

> ⚠️ 开关只能在**宿舍的 WiFi 范围内**切换（要连上路由器才能操作）。
> 所以养成习惯：**收拾书包出门前，顺手双击关掉。**

### 第一次部署时会问你

运行「一键部署.bat」到最后，它会问一句：

```
现在启用自动登录吗？（人在宿舍选 Y；马上要去教室选 n）(Y/n)
```

- 直接回车（= Y）→ 路由器立刻开始工作，宿舍 WiFi 马上能用
- 输入 n → 先不启用，等你回到宿舍再双击「校园网开关.bat」选 1

## 六、怎么知道它到底有没有在干活？

不用重新部署，看它的"工作日志"就行：

1. 浏览器打开路由器后台，或者用 PuTTY 连上路由器
2. 输入这行命令回车（一条命令就能看到开关状态 + 定时任务 + 最近日志）：

```
/data/campus/v2/bin/campus_switch.sh status
```

想单独看日志：

```
tail -20 /tmp/campus_login.log
```

**注意**：程序默认只记"出问题"的事，所以日志**大多数时候是空的 —— 这是最好的情况**，
说明网络一直好好的。日志里能看到的：

| 看到什么 | 意思 |
|---|---|
| 什么都没有 / 文件不存在 | 网络一直好好的，它不需要干活（**这是最好的情况**） |
| `当前离线（probe=...），开始认证` | 它发现掉线了，正在尝试登录 |
| `网络不可达（已尝试 3 次）` | 上游网络断了（比如宽带故障），等网络恢复会自动重试 |
| `冷静期中（已过 xx s / 1800s）` | 认证被拒（多半是密码错），它在休息 30 分钟防账号被锁 |

> 💡 想看它"成功登录"那一刻的记录？默认看不到 —— 那行属于"正常信息"级别，被过滤掉了。
> 想看的话，把 `/data/campus/v2/conf/config.ini` 里的 `log_level = warn` 改成 `log_level = info` 即可
> （日志只写在 /tmp 内存里，不会磨损路由器）。

## 七、常见问题

**Q1：窗口一闪就没了，或者提示"缺少上传工具"**
说明电脑上没装 PuTTY。去 <https://www.putty.org> 装一下（免费），再重新双击。

**Q2：提示"路由器密码不对"**
这里要填的是**路由器后台的登录密码**，不是校园网密码。
想不起来的话：看路由器背面贴的标签，或者用浏览器打开 `192.168.31.1`（小米 / 红米路由器默认地址，也可以直接访问 `miwifi.com`）试一下。
（想以后不用每次输：在同目录的 `deploy.ini` 里加一行 `SshPassword=你的路由器密码`。）

**Q3：提示"连不上路由器"**
按顺序检查：
1. 电脑连的是不是**这个**路由器的 Wi-Fi？（别连成邻居家的或手机热点）
2. 路由器地址对不对？（小米 / 红米路由器默认是 `192.168.31.1`，以前手册里写的 `192.168.99.1` 并不是小米的默认值）

**Q3.5：人已经在教室了，才发现忘了关开关，怎么办？**
开关必须连上宿舍路由器才能操作，所以**在教室是够不着的**。三个办法：
1. 回宿舍（或让室友帮着）跑一次「校园网开关.bat」关掉
2. 用手机装个 SSH 客户端（如 Termius），连上路由器后执行：
   `/data/campus/v2/bin/campus_switch.sh off`
3. 临时忍一下 —— 你在教室每登录一次，路由器 2 分钟内会把你顶下线，反复如此。
   （所以最好还是出门前顺手关掉。）

**Q4：最后提示"这一次没成功"**
**这是正常的，不用担心。** 通常是因为你现在不在学校（比如在家），本来就不需要登录校园网。
回到学校连上校园网后，它会在 2 分钟内自己登录。

**Q5：账号密码输错了怎么办？**
重新双击「一键部署.bat」，再输一遍就行 —— 新的会覆盖旧的，可以随便重跑多少次。

**Q6：校园网密码改了怎么办？**
同上，重新跑一遍。

**Q7：安全吗？密码会被别人看到吗？**
- 传输过程中密码**不会出现在命令行里**（其他程序看不到）
- 密码在路由器里的存放强度**取决于路由器固件**：
  - 路由器有 `openssl` → **AES-256 加密存放**，别人只拷走其中一个文件也还原不出原文；
  - 路由器**没有** `openssl`（**小米/红米原厂固件就是这种**）→ 降级成 base64 存放，
    **安全强度等同明文**，只靠文件权限（只有 root 能读）挡着。
    部署时如果出现这条提醒，就说明降级了：
    > ! 路由器上没有 openssl，账号密码只能以 base64 存放（安全强度等同明文，仅靠文件权限保护）
    想知道自己这台是哪种，路由器上跑一句：`/data/campus/v2/bin/cred_admin.sh status`
- ⚠️ 不管哪种模式：**能登录你路由器的人，就能看到你的密码**。所以路由器密码要设得难猜一些
- ⚠️ **别把这个密码和别的账号设成同一个**（尤其是路由器后台密码、
  以及微信/QQ/邮箱这类）；它存在路由器上，泄露面比放在你手机里大

**Q8：不想用了，怎么取消？**
两种，随便挑一种：
```
# 只停掉自动登录，程序留着（推荐，随时能再开）
/data/campus/v2/bin/campus_switch.sh off

# 彻底删掉定时任务
在路由器的定时任务里删掉这一行：
*/2 7-23 * * * [ -f /data/campus/v2/enabled ] && CAMPUS_ROOT=/data/campus/v2 /data/campus/v2/bin/campus_login.sh >/dev/null 2>&1
```

## 八、想换台电脑用？

把整个文件夹拷过去，重新双击「一键部署.bat」输一遍账号密码即可。
（程序**不保存**你的明文密码，所以换电脑必须重新输。）

## 九、它到底做了什么？（好奇再看，看不懂也没关系）

1. 先问外网："我现在能上网吗？"——访问一个固定网址，看它的回复
2. 如果不能上网 → 打开校园网登录页面，把页面里的"隐藏信息"记下来（记录你是从哪台设备来的）
3. 把你的学号、密码和这些隐藏信息一起提交给登录服务器
4. 再问一次外网："现在能上网了吗？"——能，就成功了
5. 如果连续失败 3 次 → **休息 30 分钟**再试（防止账号被锁）

另外：定时任务里带了 `[ -f .../enabled ]` 这个判断 —— **总开关关着的时候，程序连启动都不会启动**，
完全不干活，不会有任何副作用。

装进路由器的都是纯文本的小程序，你想看的话可以随时打开阅读，没有任何看不懂的"黑箱"。

---

## 十、几个提醒

- 这个程序只管"自动登录校园网"，**不会改动其他任何设置**
- 部署过程不会中断你的网络
- 如果路由器被恢复出厂设置，需要重新跑一次本程序（含总开关状态）
